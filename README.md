# Cinema Ticket Booking System
## Overview

A full-stack web application developed as a university graduation project that enables users to browse movies, view showtimes, select seats, and book cinema tickets online. The system also provides administrative features for managing movies, screening rooms, showtimes, bookings, and user accounts.

## Key Features

* User registration and authentication
* Movie browsing and search
* Showtime scheduling and management
* Interactive seat selection and reservation
* Online ticket booking and payment
* Booking history management
* Movie and showtime administration
* Real-time seat status synchronization
* Responsive web design
